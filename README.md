# HOTEL MANAGEMENT SYSTEM

Hotel Management System adalah program C++ untuk mengelola sistem pemesanan kamar hotel secara sederhana. 

## Fitur

- melihat ketersediaan kamar
- booking kamar
- mencari data tamu
- laporan data tamu 
- menghitung total pendapatan
- penyimpanan data ke dalam file teks
